# HackConcursos

Sistema de mentoria digital baseada em IA para concurseiros. O foco é no estudo estratégico e técnicas de "hackear" a banca, priorizando o que realmente cai na prova.

## Funcionalidades
- Diagnóstico de nível por disciplina.
- Geração de plano de estudos personalizado e intercalado.
- Mentor de IA integrado (Gemini/OpenAI).
- Sistema de simulados e acompanhamento de progresso.

## Tecnologias
- PHP 8.x
- MySQL
- JavaScript / CSS Vanilla
- IA: Google Gemini / OpenAI
